How it works

No link beats a wrong link.

  1. Claude reads the player

    Just the title and artist. Post text, playlist names, device names and badges are ignored.

  2. Every platform, at once

    Apple Music, Spotify, Deezer and YouTube are searched at the same time.

  3. Only exact matches

    Same title, same artist, or no link. Remixes, covers, live versions and fan uploads don't count.

  4. Instant the second time

    Results are cached, so the same screenshot or song comes back in milliseconds.
